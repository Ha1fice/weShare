# Phase 1 手工验收脚本（T6.2）

> 需求：架构文档 §14 T6.2。
> 覆盖范围：登录/登出、注册防枚举、空间与成员管理、目录节点 CRUD+拖放、文档壳、权限边界、回收站全链路、跨用户隔离。
> 使用方式：逐节勾选，每步记录「步骤 → 预期结果 → 实际结果」。自动化测试已覆盖的部分在「备注」列给出对应测试文件。

## 0. 前置条件

| 项 | 值 |
| --- | --- |
| Node | ≥ 22 |
| pnpm | 9.14.4（`corepack enable && corepack prepare pnpm@9.14.4 --activate`） |
| 安装依赖 | `pnpm install` |
| 初始化数据库 | `pnpm db:migrate && pnpm db:seed` |
| 启动服务 | `pnpm dev`（web :5173 / api :3000 / collab :3100） |
| 种子管理员 | `admin@weshare.local` / `weshare-admin-2026`（`packages/db/scripts/seed.ts`） |
| 注册开关 | 本地 `.env` 需 `ALLOW_REGISTER=true` |

| 账号 | 空间角色 | 用途 |
| --- | --- | --- |
| admin@weshare.local | owner | 种子管理员，主验账号 |
