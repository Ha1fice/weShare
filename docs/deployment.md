# 部署说明

> 面向"把 weShare 跑起来给别人用"的场景。本地开发看 [dev-setup.md](dev-setup.md)。

## 两种身份形态

weShare 有两种入口，**二选一**，不要同时对外暴露：

| 形态             | 打开方式                                             | 身份来源                 | 适用                   |
| ---------------- | ---------------------------------------------------- | ------------------------ | ---------------------- |
| 密码账号（默认） | 无需配置                                             | 邮箱 + 密码，会话 Cookie | 生产、有真实资料的环境 |
| 免密身份（试用） | `DEVICE_IDENTITY=true` + `VITE_DEVICE_IDENTITY=true` | 设备指纹派生的 `userId`  | 内网、试用、演示机     |

### 免密模式的边界（部署前必须读完）

- **`deviceKey` 不是凭证。** 知道它的人可以冒充该身份取得会话。指纹可伪造，本地盐可复制。
- **换浏览器 / 清缓存 = 新身份新空间。** 旧内容仍在原身份下，界面里没有"找回"入口。
- **空间隔离不受影响。** 身份只回答"你是谁"；能不能读某篇文档仍由服务端
  `effectiveRole` + ACL 判定。免密不放大任何文档权限。
- **只放得下"用完就丢"的内容。** 不要在这台机器上存真实资料。

## 部署一台免密模式的试用机

```bash
cp .env.trial.example .env
# 按文件里的"必改"三项填：CORS_ORIGINS / ALLOWED_ORIGINS / SECURE_COOKIE
pnpm install
pnpm db:migrate
pnpm build
pnpm dev          # 或你惯用的进程管理方式
```

模板文件 `.env.trial.example` 与 `.env.example` 的**唯一区别**就是两个免密开关为 `true`。
代码默认值始终是 `false`，`.env.example` 也保持 `false`：试用配置不该被当成默认值抄进生产。

### 这台机器要标注

对外说明和部署记录里写清楚：

> **本机为 weShare 免密模式（试用）**：任何人打开页面即可用任意名字进入，
> 身份保存在浏览器本地。请不要在本机存放真实或敏感资料。
> 需要账号登录与访问控制，请部署密码模式实例。

挂域名时 `SECURE_COOKIE` 必须改 `true`——免密模式同样下发会话 Cookie，
不加 `Secure` + `__Host-` 前缀，子域可覆盖会话。

## 回到密码模式

删掉 `.env` 里两行开关键（或置 `false`），重新构建 web（`VITE_*` 是构建期注入），
重启 api 与 web。原本由免密产生的账号仍留在库里（`*@device.weshare.local`，占位邮箱不可路由），
若确认不再需要，可按邮箱域名清掉。
